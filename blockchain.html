STAGE 03

TO-DO DAPP — SOLIDITY + REACT

★ OVERVIEW

A To-Do List application integrating Solidity smart contracts deployed using Hardhat, with a React frontend for user interaction. Fully decentralised and tamper-proof.

★ PROTOTYPE
★ PROBLEM STATEMENT

Traditional To-Do apps rely on centralised databases, making them vulnerable to:

  • Data Manipulation & Loss: Users have no real ownership of their tasks. Data can be lost due to server failures or security breaches.
  • Lack of Transparency: No verifiable record of task modifications or completions. Users must trust the service provider.
★ USER RESEARCH

Users seek a secure, transparent, and decentralised task management solution to ensure data integrity, ownership, and verifiable task history without relying on centralised services.

★ SOLUTION
  • Decentralised Task Management: Smart contracts on Ethereum ensure tasks are immutable and tamper-proof. Users have full control without a central authority.
  • Gasless Transactions: Meta-transactions (Gasless UX) reduce gas fees, making frequent task updates affordable.
  • Transparent Task History: Each task update stored on-chain ensures auditable history. Users can verify who created, updated or completed a task.
★ OUTPUT

A fully functional decentralised To-Do List DApp where users can securely add, update, and track tasks on the blockchain with MetaMask integration and a React-based UI.

★ FUTURE IMPROVEMENTS

Enhance UI with better styling, add 'Mark as Completed' and task filtering, enable persistent storage, and improve error handling for a smoother user experience.
